================================================================================
  INSTRUCCIONES PARA CONSTRUIR Y EJECUTAR LA APLICACIÓN CON DOCKER
================================================================================

PASO 1: CONSTRUIR LAS IMÁGENES
------------------------------
Abre una terminal en la carpeta C:\Backent y ejecuta:

    docker-compose build

Este comando construirá las imágenes de:
  - Backend (Spring Boot)
  - Frontend (Angular con Nginx)
  - MySQL (se descarga automáticamente)

Tiempo estimado: 5-10 minutos (primera vez)


PASO 2: INICIAR LOS CONTENEDORES
---------------------------------
Ejecuta:

    docker-compose up -d

El flag -d ejecuta los contenedores en segundo plano (detached mode).


PASO 3: VERIFICAR EL ESTADO
----------------------------
Verifica que todos los contenedores estén corriendo:

    docker-compose ps

Deberías ver 3 contenedores con estado "Up" y "healthy" o "starting".


PASO 4: VER LOGS (OPCIONAL)
----------------------------
Para ver los logs en tiempo real:

    docker-compose logs -f

Presiona Ctrl+C para salir.


PASO 5: ACCEDER A LA APLICACIÓN
--------------------------------
Una vez que los contenedores estén listos:

  Frontend:  http://localhost:4200
  Backend:    http://localhost:8000/clinica/v1
  Swagger:    http://localhost:8000/clinica/v1/swagger-ui/index.html

El usuario administrador se crea automáticamente:
  Usuario: admin
  Contraseña: admin123


COMANDOS ÚTILES
---------------

Ver logs de un servicio específico:
    docker-compose logs -f backend
    docker-compose logs -f frontend
    docker-compose logs -f mysql

Detener los contenedores:
    docker-compose stop

Reiniciar los contenedores:
    docker-compose restart

Detener y eliminar contenedores:
    docker-compose down

Detener y eliminar contenedores + volúmenes (⚠️ elimina datos):
    docker-compose down -v

Reconstruir imágenes:
    docker-compose build --no-cache

Reconstruir y reiniciar:
    docker-compose up -d --build


VERIFICACIÓN DEL FUNCIONAMIENTO
--------------------------------

1. Verificar que los contenedores estén corriendo:
   docker-compose ps

2. Verificar backend (desde navegador o terminal):
   http://localhost:8000/clinica/v1/swagger-ui/index.html
   
   O desde terminal:
   curl http://localhost:8000/clinica/v1/usuario/listar

3. Verificar frontend:
   Abrir en navegador: http://localhost:4200
   Debería mostrar la página de login

4. Verificar MySQL:
   docker exec -it clinica-mysql mysql -u root -p1234 -e "SHOW DATABASES;"


SOLUCIÓN DE PROBLEMAS
----------------------

Si un contenedor no inicia:
  1. Ver logs: docker-compose logs [nombre-servicio]
  2. Verificar puertos: asegúrate que 8000, 4200 y 3307 estén libres
  3. Reconstruir: docker-compose build --no-cache [nombre-servicio]

Si el backend no se conecta a MySQL:
  1. Verificar que MySQL esté saludable: docker-compose ps mysql
  2. Esperar unos segundos más (el backend espera a que MySQL esté listo)

Si el frontend no carga:
  1. Verificar logs: docker-compose logs frontend
  2. Verificar que el build se completó correctamente
